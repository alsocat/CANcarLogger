Clear fault codes

Ignition on, engine off. Takes about 30 seconds.

Before you clear
  • Clearing turns the light off but doesn't fix anything. A fault that's still there comes back, often within a drive.
  • Emissions readiness resets. The car fails a smog or emissions test until it's been driven normally for a few days, usually 50–100 miles.
  • The record of when each fault happened is erased. Note the codes first if you'll want them.
